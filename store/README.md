# Выпуск в магазины расширений

Пошаговая инструкция для сопровождающего. Всё, что нужно вставить в поля карточек, уже готово:

| Файл | Что внутри |
|---|---|
| [listing.md](listing.md) | Название, описания на русском и английском, категории, поисковые слова |
| [privacy-answers.md](privacy-answers.md) | Ответы для вкладки Privacy: single purpose, обоснования разрешений, раскрытие данных |
| [reviewer-notes.md](reviewer-notes.md) | Заметки для проверяющих на английском, инструкция сборки для Firefox |
| [images/](images/) | Иконка, скриншоты, промо-плитки, логотип |

## Перед началом

1. **Тестовый аккаунт FunPay для проверяющих.** Firefox и Edge требуют логин, если без аккаунта функции не видны. Заведите отдельный аккаунт, не давайте основной. Логин и пароль впишите в заметки из `reviewer-notes.md`.
2. **Двухфакторная защита.** Обязательна для Google и Mozilla. Включите её заранее.
3. **Архивы.** Возьмите из последнего выпуска на GitHub (Releases) или соберите сами: `npm run zip` и `npm run zip:firefox`. Получатся файлы в `.output/`:
   - `wingman-X.Y.Z-chrome.zip` - для Chrome, Edge и Opera;
   - `wingman-X.Y.Z-firefox.zip` и `wingman-X.Y.Z-sources.zip` - для Firefox.

## Chrome Web Store

Из него же ставят расширения Яндекс Браузер и Opera, поэтому это главный магазин.

Опубликовано: [bbakbcjajkhepmflnpdgbokkbipmcjdk](https://chromewebstore.google.com/detail/bbakbcjajkhepmflnpdgbokkbipmcjdk). Этот ID - значение секрета `CHROME_EXTENSION_ID`. Шаги ниже - для первой публикации.

1. Зарегистрируйтесь в [кабинете разработчика](https://chrome.google.com/webstore/devconsole). Взнос разовый, 5 USD. Российская карта, скорее всего, не пройдёт: Google с 2022 года не принимает платежи из России, понадобится карта другой страны.
2. Выберите статус **non-trader**, если не продаёте расширение и не зарабатываете на нём.
3. Нажмите «New item» и загрузите `wingman-X.Y.Z-chrome.zip`.
4. **Store listing:**
   - описание - раздел «Подробное описание» из `listing.md`;
   - категория - Productivity → Tools, язык - русский;
   - иконка - `images/store-icon-128.png`;
   - скриншоты - `images/1-sales.png` … `images/5-popup.png`;
   - малая плитка - `images/promo-small-440x280.png`, большая - `images/promo-marquee-1400x560.png`.
5. **Privacy** - всё из `privacy-answers.md`, раздел за разделом.
6. **Distribution** - Public, все страны.
7. Отправьте на проверку. Обычно она занимает несколько дней, у нового разработчика бывает до трёх недель.

## Firefox Add-ons

1. Войдите на [addons.mozilla.org/developers](https://addons.mozilla.org/developers/) через Mozilla Account. Регистрация бесплатная.
2. «Submit a New Add-on» → «On this site» → загрузите `wingman-X.Y.Z-firefox.zip`.
3. На вопрос об исходниках ответьте «Yes» и приложите `wingman-X.Y.Z-sources.zip`.
4. Карточка:
   - описание из `listing.md` (можно русское и английское);
   - категории Shopping и Alerts & Updates;
   - лицензия GPL-3.0;
   - сайт поддержки и политика конфиденциальности - ссылки из `listing.md`;
   - скриншоты те же, что для Chrome.
5. В «Notes to reviewer» вставьте блок из `reviewer-notes.md` с данными тестового аккаунта.

Проверенная автоматически версия публикуется сразу. Вручную могут проверить и после публикации.

## Microsoft Edge Add-ons

1. Зарегистрируйтесь в [Partner Center](https://partner.microsoft.com/dashboard/microsoftedge/overview) как Individual. Бесплатно, но страну и тип аккаунта потом не сменить.
2. «Create new extension» → загрузите `wingman-X.Y.Z-chrome.zip`.
3. Карточка:
   - описание из `listing.md` (не короче 250 символов);
   - логотип `images/logo-300.png`;
   - плитки `images/promo-small-440x280.png` и `images/promo-marquee-1400x560.png`;
   - скриншоты те же;
   - поисковые слова из `listing.md`.
4. Privacy - те же ответы, что для Chrome.
5. В «Notes for certification» вставьте блок из `reviewer-notes.md`.

Проверка - до 7 рабочих дней.

## Opera Add-ons

1. Войдите на [addons.opera.com/developer](https://addons.opera.com/developer/).
2. Загрузите `wingman-X.Y.Z-chrome.zip`.
3. Скриншоты Opera принимает не больше 800×600, для неё есть уменьшенные копии в `images/opera/`.
4. Код в архиве минифицирован, поэтому в заметках обязательно оставьте ссылку на исходники и инструкцию сборки из `reviewer-notes.md`.

## Яндекс Браузер

Своего магазина для сторонних расширений у Яндекса нет. Браузер ставит расширения из Chrome Web Store и Opera Add-ons, поэтому после публикации в Chrome отдельно ничего делать не нужно.

## Где могут отказать

- **Автоответы (Chrome, правило о спаме).** Нельзя слать сообщения, которые пользователь не видел. У нас автоответы по умолчанию выключены, все тексты пишет сам продавец, а включение показывает, что именно уйдёт. Если спросят - отвечайте этим.
- **Автоподнятие (Edge, правило о ботах).** Edge запрещает автоматизацию, которая «манипулирует функциями платформы». Wingman нажимает только стандартную кнопку поднятия FunPay и только когда FunPay это разрешает. Если откажут, стоит переписать описание: не «автоматизация», а «напоминание и поднятие в одно нажатие».
- **Логотипы.** На скриншотах есть интерфейс и логотип FunPay, в расширении - логотипы банков СБП. В описании прямо сказано, что проект не связан с FunPay. Если магазин попросит, логотипы можно убрать со скриншотов.

## После первой публикации

Дальше новые версии уходят сами: тег `vX.Y.Z` запускает `.github/workflows/release.yml`. Для этого добавьте секреты репозитория (Settings → Secrets and variables → Actions). Список секретов и где их взять - в [CONTRIBUTING.md](../CONTRIBUTING.md#выпуск-версии). Opera официального API не даёт, новые версии туда загружаются вручную.
