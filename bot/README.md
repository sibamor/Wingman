# Бот Wingman для Discord

Публичный бот для торговых Discord-серверов вокруг FunPay. Читает только публичные страницы funpay.com и не просит данные аккаунта.

| Команда | Что делает |
|---|---|
| `/seller` | Карточка продавца: рейтинг, отзывы, стаж, лоты по разделам, последние отзывы |
| `/price` | Цены в разделе: минимум, медиана, самые дешёвые лоты, цены по вариантам |
| `/watch` | Уведомление в личные сообщения или канал, когда в разделе появился лот дешевле заданной цены |
| `/fee` | Сколько получит продавец и заплатит покупатель при заданной комиссии |
| `/protect` | Защита от поддельных сайтов FunPay и сообщений «от администрации FunPay»: предупредить или удалить |
| `/news` | Публиковать новые версии расширения Wingman в канал |
| `/wingman` | Список команд и ссылки |

По умолчанию защита на каждом сервере включена в режиме «предупреждать ответом».

## Запуск

Нужен Node.js 24.

```
cd bot
npm ci
cp .env.example .env
npm start
```

В `.env`:

- `DISCORD_TOKEN` - токен бота со страницы Bot в Discord Developer Portal;
- `DEV_GUILD_ID` - необязательно: ID тестового сервера, тогда команды регистрируются только там и появляются сразу.

Состояние (настройки серверов, слежения, запомненные ники) хранится в `data/state.json`.

Из привилегированных интентов боту нужен только Message Content: по нему работает защита от мошенников.

## Как устроено

- `src/funpay.ts` - запросы к FunPay по очереди с паузой 1,5 с и кэшем: раздел 4 минуты, профиль 10 минут, список разделов 12 часов.
- Разбор страниц общий с расширением: `lib/fp-pages.ts`, `lib/rows.ts`, проверка на мошенников - `lib/scam.ts`.
- Слежения проверяются раз в 10 минут, новости - раз в 30 минут из выпусков на GitHub.

```
npm run check
npm test
```
